# Angular and Gin Chat MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver the approved anonymous public-room chat MVP in the existing Angular and Go repository.

**Architecture:** One Gin chat executable owns the room hub and its bounded memory repository. REST exposes room metadata/history and WebSockets carry atomic initial snapshots, messages, and presence. Angular maintains browser-only connection state through a separate service and renders a responsive chat screen.

**Tech Stack:** Installed Angular 21, signals, HttpClient, Vitest, Go 1.27.2, Gin 1.12.0, Gorilla WebSocket 1.5.3, and Godog 0.16.0.

Use `docs/superpowers/specs/2026-10-14-chat-mvp-design.md` as the full behavior and protocol contract. Work in `/Users/geloes/Documents/Codex/2026-10-14/che/work/chat-mvp` on `feat/chat-mvp`. Preserve the original checkout's untracked Go module files; copies are already in this worktree. The installed Node dependencies are reused through an ignored symlink. Do not publish or push.

## File responsibilities

- `cmd/chat/main.go`: environment configuration, server startup, signals, and shutdown.
- `internal/chat/model.go`: rooms, messages, participants, typed events, and validation.
- `internal/chat/store.go`: repository interface and thread-safe bounded memory history.
- `internal/chat/hub.go`: serialized room registration, publication, presence, and bounded client queues.
- `internal/transport/server.go`: Gin endpoints, JSON errors, allowed origins, and upgrade.
- `internal/transport/socket.go`: the single-reader/single-writer lifecycle, pings, deadlines, and cleanup.
- `features/chat.feature`, `bdd/chat_test.go`: public behavior and real transport step definitions.
- `internal/chat/*_test.go`, `internal/transport/*_test.go`: boundary, lifecycle, and concurrency regression checks.
- `src/app/chat/chat.models.ts`: exact REST/WebSocket TypeScript contracts.
- `src/app/chat/chat.service.ts`: rooms, connection states, snapshots, retries, teardown, and sending.
- `src/app/chat/chat.service.spec.ts`: controllable socket/timer tests of real service behavior.
- `src/app/app.ts`, `app.html`, `app.css`, `app.spec.ts`: room navigation, guest forms, screen behavior, and rendered interaction tests.
- `src/app/chat/conversation.ts`, `conversation.html`, `conversation.css`: message rendering, native locale timestamps, keyboard input, composer, and scroll handling.
- `src/styles.css`: shared visual tokens and baseline styles.
- `proxy.conf.json`, `angular.json`, `package.json`: development routing and runnable commands.
- `README.md`: startup, BDD workflow, protocol, limits, and future services.
